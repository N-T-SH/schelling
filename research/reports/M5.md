# M5 Paraphrase augmentation: report

**Result (null): training with offline question paraphrases did not improve Twin-2K-500 `heldout_person` validation NLL.** The augmented model scores 0.9879 <!-- src: research/reports/M5-bootstrap.json#aug_mean_nll --> against 0.9874 <!-- src: research/reports/M5-bootstrap.json#base_mean_nll --> for the same model without paraphrases (3 seeds each); the paired difference is +0.0005 <!-- src: research/reports/M5-bootstrap.json#aug_minus_m4b.mean_diff --> NLL with a paired bootstrap interval from -0.0014 <!-- src: research/reports/M5-bootstrap.json#aug_minus_m4b.ci95.0 --> to +0.0023 <!-- src: research/reports/M5-bootstrap.json#aug_minus_m4b.ci95.1 -->, so it includes zero. Positive means augmentation is worse. Everything here is the validation partition; the test partition was never read.

## What was run

- Model: the M4b two-tower (`configs/twotower-a.yaml`). Augmented runs use `configs/m5-aug.yaml`: up to 6 stored rewordings of each training question stem, one swapped in for half the rows at each step (decision 0006). Options, scale labels and answers are unchanged, and validation uses the original wording.
- Paraphrases: gpt-oss-120b via Fireworks, 435 unique question texts, generated once offline, filtered for copies, duplicates, length and changed numbers (A19, A20 in `research/ASSUMPTIONS.md`). 45 texts have fewer than two rewordings and keep their original wording.
- Seeds 0 to 2, harness-evaluated (`scripts/run_m5.sh`). Baseline seeds were re-run, not reused. Paired bootstrap over 206 persons, 10,000 resamples, seeds averaged per person (`research/reports/M5-bootstrap.json`).
- Not run: `heldout_item` (where wording robustness should show), five seeds, treatment-effect metrics, the test partition.

## Reading

This data does not support the idea that wording diversity helps person-level prediction on questions the model has already seen: the training and validation items are the same questions, so there is nothing for a robust wording to fix. The one place the idea could still pay off is `heldout_item`, which was not run. Treat this as a null result for `heldout_person`, not as evidence against augmentation in general.
